# 🩻 AI Mentor — הנדסה ביו-רפואית

מערכת ליווי AI שבועית לתלמידי כיתה י' בפרויקט "בניית מודל AI לאבחון רפואי"
(אבחון שברים בצילומי רנטגן). כוללת צ'אט מבוסס Gemini לכל תלמיד/ה (3 שאלות
מוערכות שבועיות + עזרה חופשית בלתי מוגבלת), ופאנל ניהול למורה.

מבוסס על האפיון שגובש מראש (ראו את מסמך האפיון בשיחה שבה נבנה הפרויקט) —
המימוש כאן משקף את FR-A עד FR-F שם.

## מבנה הפרויקט

```
index.html              נקודת הכניסה
css/style.css           עיצוב קליני כהה, מותאם מובייל
js/config.js            הגדרות גלובליות (כולל כתובת ה-API)
js/api.js               שכבת תקשורת מול השרת + מצב פיתוח מקומי
js/ui.js                רכיבי ממשק משותפים (טוסט, פס עליון)
js/auth.js              מסך התחברות + חיוב החלפת סיסמה בכניסה ראשונה
js/excelImport.js       פרשור קובץ Excel של תלמידים (SheetJS) + גזירת פרטי התחברות
js/main.js              ניתוב בין מסך תלמיד/מורה
js/studentChat.js       הצ'אט המאוחד עם ה-AI Mentor (תמונות + 3 שאלות מוערכות + עזרה חופשית)
js/teacherDashboard.js  פאנל ניהול: ייבוא, נושא שבועי, מעקב ציונים, תמלולים, ייצוא
backend/Code.gs         קוד השרת ל-Google Apps Script (Sheets + Gemini)
```

## הרצה מקומית מיידית (ללא שרת)

כולל **מצב פיתוח מקומי** שמדמה את רוב ה-API באמצעות `localStorage`. שיחת
ה-AI Mentor עצמה מוצגת במצב פיתוח כתסריט מדומה קבוע (לא AI אמיתי) — טוב
לבדיקת הממשק, לא לבדיקת איכות השאלות בפועל. יש להריץ משרת HTTP מקומי (לא
לפתוח את `index.html` ישירות כקובץ, כי הדפדפן חוסם ES Modules ב-`file://`):

```bash
py -m http.server 8000
```

ואז לפתוח `http://localhost:8000`.

משתמשי ברירת מחדל במצב הפיתוח:
- **מורה/ניהול:** `admin` / `admin123`
- **תלמידה לדוגמה:** `מיכל5678` / `140810`

## חיבור לשרת אמיתי (Google Apps Script + Sheets + Gemini)

1. פתחו [sheets.google.com](https://sheets.google.com) וצרו גיליון חדש (למשל "AI Mentor - נתונים").
2. בתפריט **הרחבות ← Apps Script** יפתח עורך הסקריפטים המחובר לגיליון.
3. מחקו את התוכן שבקובץ `Code.gs` שנפתח כברירת מחדל, והדביקו במקומו את התוכן
   המלא של [`backend/Code.gs`](backend/Code.gs) מתוך הפרויקט הזה.
4. **הגדירו מפתח Gemini**: ב-Apps Script Editor → ⚙️ **Project Settings** →
   **Script Properties** → הוסיפו מאפיין בשם `GEMINI_API_KEY` עם המפתח שלכם
   (נוצר ב-[aistudio.google.com/apikey](https://aistudio.google.com/apikey)).
5. לחצו **פריסה (Deploy) ← פריסה חדשה (New deployment)**.
   - סוג: **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone** (כדי שהאפליקציה תוכל לקרוא לשרת ללא התחברות Google)
6. אשרו הרשאות (כולל גישה ל-Drive וליצירת מסמכי Docs — נדרש ליומני התלמידים
   ולייצוא), ואז העתיקו את כתובת ה-**Web app URL** שמתקבלת (מסתיימת ב-`/exec`).
7. הדביקו את הכתובת בשדה `API_URL` בקובץ [`js/config.js`](js/config.js).
8. **הפעילו את הייצוא השבועי האוטומטי**: בעורך ה-Apps Script, בתפריט הפונקציות
   בראש המסך בחרו `installWeeklyTrigger` ולחצו ▶ Run פעם אחת (מריץ Trigger
   קבוע לכל יום ראשון ב-20:00 — ניתן לשנות בקוד אם רוצים יום/שעה אחרים).
9. בפעם הראשונה שקוראים לשרת, הוא ייצור אוטומטית את הגיליונות הדרושים
   (`Users`, `WeeklyTopics`, `WeeklyCheckIns`, `HelpChatLog`) עם משתמש מורה
   ברירת מחדל (`admin`/`admin123`) — **מומלץ להחליף מיד** דרך פאנל הניהול.
10. פרסמו את התיקייה (index.html + css/ + js/) לכל אירוח סטטי (GitHub Pages,
    Google Sites, שרת בית הספר).

### עדכון פריסה קיימת
כל שינוי בקוד ה-`Code.gs` דורש **Manage deployments ← Edit ← New version** כדי
שהשינויים ייכנסו לתוקף (Apps Script לא מעדכן פריסות קיימות אוטומטית).

### תחילת שנה — הגדרת שבוע ראשון וייבוא תלמידים
1. בפאנל הניהול, הזינו "נושא השיעור השבועי" ולחצו **שבוע חדש** כדי לפתוח את שבוע 1.
2. הכינו קובץ Excel עם העמודות: שם פרטי, שם משפחה, תעודת זהות מלאה, תאריך
   לידה, קבוצה, איבר התמחות קבוצתי, אסטרטגיית מודל (ערכים: תקן/הטיות/רעשים).
3. העלו את הקובץ בפאנל הניהול ← "ייבוא תלמידים מקובץ Excel" ← נתחו ← ייבוא.
   הקובץ נקרא ומעובד **בדפדפן בלבד** (SheetJS) — תעודת הזהות המלאה לעולם לא
   נשלחת לשרת, רק 4 הספרות האחרונות (לצורך שם המשתמש).

## אבטחה ופרטיות - הערות חשובות

- הסיסמאות נשמרות כגיבוב SHA-256 בלבד. הסיסמה הראשונית (תאריך לידה) חזויה
  יחסית, ולכן **כל תלמיד/ה מחויב/ת להחליף סיסמה בכניסה הראשונה**.
- תעודת זהות מלאה **אינה נשמרת בשום שלב** — נקראת ומעובדת בדפדפן המורה בלבד
  בזמן ייבוא האקסל, ורק 4 הספרות האחרונות (לצורך שם המשתמש) מגיעות לשרת.
- זהו פתרון אימות פשוט המתאים לכלי כיתתי פנימי — אין בו rate limiting או
  ניהול הרשאות מתקדם. לא מיועד לאחסון מידע רפואי אמיתי של מטופלים: יש
  להשתמש רק בתמונות ממאגרים ציבוריים מאושרים (NIH/Kaggle וכד', anonymized).
- תמונות התלמידים נשמרות ב-Drive של המורה (לא בגיליון עצמו), ביומני Docs
  אישיים לכל תלמיד/ה.

## עלות Gemini API

מוגדר כברירת מחדל למודל **Gemini 2.5 Flash-Lite** (`GEMINI_MODEL` ב-`Code.gs`)
- הזול ביותר במשפחת Gemini, מספיק לצורך זה. הערכת עלות (נכון לאוגוסט 2026):
גם בשימוש כבד (60 תלמידים, כולל צ'אט עזרה בלתי מוגבל) - כ-$1-3 לחודש.
מומלץ להגדיר Billing Alert בפרויקט ה-Google Cloud המשויך על סף $5.

## הרחבת שכבת ה-API

| פונקציה | תיאור |
|---|---|
| `authenticateUser(user, pass)` | אימות התחברות |
| `changePassword(studentId, newPassword)` | החלפת סיסמה (ע"י התלמיד/ה עצמו/ה) |
| `resetStudentPassword(studentId, newPassword)` | איפוס סיסמה ע"י המורה |
| `importRoster(students)` | ייבוא רשימת תלמידים (אחרי פרסור Excel בדפדפן) |
| `getStudentContext(studentId)` | פרטי התלמיד/ה + שבוע נוכחי + זיכרון שבוע קודם |
| `sendMentorMessage(studentId, history, images, elapsedSeconds)` | הודעה בצ'אט המאוחד |
| `getCurrentWeek()` / `startNewWeek(topic)` / `updateCurrentWeekTopic(topic)` | ניהול נושא שבועי |
| `getDashboard()` | טבלת מעקב לכל התלמידים (ציונים לפי נוסחת 80%) |
| `getStudentTranscripts(studentId)` | תמלולי צ'ק-אין + עזרה חופשית |
| `setManualGrade(checkInId, score, note)` | דריסת ציון ידנית |
| `exportWeeklyReport()` | הרצה ידנית של הייצוא (רץ גם אוטומטית פעם בשבוע) |
